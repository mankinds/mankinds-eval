# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability in mankinds-eval, please report it
by opening a private security advisory on GitHub:

1. Go to the repository's Security tab
2. Click "Report a vulnerability"
3. Provide a detailed description of the vulnerability

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and provide a detailed response
within 7 days indicating next steps.

Please do not disclose the vulnerability publicly until we have had a chance
to address it.

## Security Best Practices

When using mankinds-eval:

- Keep your dependencies up to date
- Store API keys in environment variables, not in code
- Review LLM provider configurations before deployment
- Use the latest version of the library
